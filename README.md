# Лазейка

Личный VPN-клиент для Windows 10/11: mihomo (VLESS/XHTTP/Reality, AmneziaWG 1.0–3.1,
Hysteria2, Trojan, подписки) и zapret от Flowseal в одном приложении с умной
маршрутизацией.

## Как это устроено

- `Lazeyka.exe` — одна программа: значок в трее, локальный веб-интерфейс
  (открывается в окне Edge без прав администратора), управление движками.
- mihomo и zapret не встроены: при первом использовании скачиваются с
  официальных релизов GitHub (MetaCubeX/mihomo, Flowseal/zapret-discord-youtube),
  файл сверяется с SHA-256 из релиза.
- Всё лежит в `C:\ProgramData\Lazeyka`; права на папку — только администраторы
  (пользователи могут читать программу, но не данные: там ключи серверов).
- Права администратора нужны для TUN-адаптера и драйвера WinDivert. UAC
  спрашивается один раз при установке, дальше запуск идёт через задачу
  планировщика «Lazeyka» (и «Lazeyka Autostart» для автозапуска).
- Если на сетевой карте включена пересылка пакетов (её включают общий доступ к
  интернету и мобильный хот-спот), Windows отправляет соединения самого VPN
  обратно в туннель. Пока VPN включён, Лазейка выключает пересылку на картах с
  маршрутом по умолчанию и возвращает её при отключении (и при следующем
  запуске, если программа закрылась аварийно).

## Управление

- Слева на любой вкладке: переключатели VPN и zapret, сервер для
  заблокированного, стратегия zapret (те, что помогли на этом компьютере, —
  сверху), страна выхода, пинг, скорость и время работы. Что показывать —
  в «Настройках», всё лишнее сворачивается одной кнопкой.
- То же в меню значка в трее: подменю «Сервер для заблокированного» и
  «Стратегия zapret».

## Маршруты по умолчанию

| Что | Куда |
|---|---|
| Российские сайты, адреса и программы (Яндекс, 1С, антивирус) | напрямую |
| YouTube, Discord | через zapret; если zapret не работает — сами переходят на сервер |
| Telegram, WhatsApp | через сервер с UDP (AmneziaWG/Hysteria2), иначе любой |
| ИИ-сервисы | только через свои серверы |
| Заблокированное в РФ и закрытое для РФ (списки itdoginfo) | свои серверы → подписка |
| Торренты | раздача напрямую, трекеры из списка блокировок — через сервер |
| Игровые лаунчеры, прочий UDP | напрямую |
| Всё остальное | напрямую (переключается) |

## Сборка

Нужен Go 1.24+. Только стандартная библиотека, внешних модулей нет.

```sh
go test ./...
# ресурсы exe (значок, манифест, версия) — нужны llvm-rc и llvm-cvtres:
./tools/make_syso.sh
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H=windowsgui" -o dist/Lazeyka.exe .
```

Значки рисует `tools/make_icons.py` (Pillow): `python3 tools/make_icons.py assets/icons`.

## Режим разработки (Linux/macOS)

```sh
LAZEYKA_HOME=/tmp/lz LAZEYKA_MIHOMO=/path/to/mihomo go run . --dev
```

Без TUN, трея и zapret; адрес интерфейса печатается в консоль.

## Удаление

Настройки → «Удалить Лазейку»: задачи, ярлыки, служба WinDivert и папка
`C:\ProgramData\Lazeyka` удаляются.
